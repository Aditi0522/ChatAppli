## Sphere

Sphere is a go web chat application for users who truly wish to keep their data private and secure.  

For the basic MVP I am planning on adding Authentication, one on one chat, group chat, media sharing, and basic feature of read/ delievered reciept. We will keep our focus on security and data integrity and to ensure that, many more features, protocols and paradigms will have to be followed which I am currently researching.

I started building this project mainly after the AI boom that has been happening as of late (yeah real early I am) but things have taken the turn for absolute worst and I wanted to contribute towards making a platform where people could truly access communication channels without worrying about their privacy. Also another main reason for taking up this project was so that I could better understand high level backend projects and essentially scale this (Wanted to write good, clean code following good architecture choices and understand data flow) 

Yeah that's about it for now. Will keep this updated.
